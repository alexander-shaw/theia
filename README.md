# THEIA

THEIA is a planned native iOS application that assists blind and low-vision individuals in locating rooms and other significant locations within a building. This repository holds project documentation, academic deliverables for CptS 484, and future application source as development progresses.

## Project Overview

THEIA helps blind and low-vision users navigate between rooms and other significant locations indoors. It is planned as an accessible iOS app that provides navigation guidance and emergency dial-out, using simulated beacon signals in the prototype.

See the [preliminary project plan](docs/CPTS-484-Preliminary-Project-Plan.pdf) for full scope, success criteria, and assumptions.

## Development

THEIA is planned as a native iPhone app using Xcode and Swift, with Apple accessibility and device frameworks (for example VoiceOver, audio guidance, and haptic feedback) where appropriate. Phase I tooling also includes Figma or equivalent for interface prototyping, Google Drive for documentation, GitHub for version control, and Discord for coordination.

Verified local build and setup instructions will be added when application source is present in the repository.
